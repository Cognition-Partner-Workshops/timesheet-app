# Timesheet iOS Client

A native SwiftUI iOS client for the Timesheet backend (`backend/`, Express on port 3001).

## Features

- Email-only sign in (matches the backend's passwordless auth via the `x-user-email` header)
- Clients: list, search, create, edit, swipe-to-delete
- Work entries: list with client filter, total hours, create, edit, swipe-to-delete
- Per-client report: total hours, entry count, full entry history
- Export reports as PDF or CSV and share via the iOS share sheet
- Configurable server URL (Settings tab or from the login screen)

## Requirements

- macOS with Xcode 15+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)
- The backend running locally: `cd backend && npm install && npm run dev` (port 3001)

## Build & Run

```bash
cd ios
xcodegen generate            # creates TimesheetApp.xcodeproj from project.yml
open TimesheetApp.xcodeproj  # then run on an iOS Simulator
```

Or from the command line:

```bash
xcodebuild -project TimesheetApp.xcodeproj -scheme TimesheetApp \
  -destination 'platform=iOS Simulator,name=iPhone 15' build
```

The default server URL is `http://localhost:3001`, which works out of the box in the
iOS Simulator when the backend runs on the same Mac. For a physical device, set the
server URL in Settings to your Mac's LAN IP (e.g. `http://192.168.1.10:3001`).

## Project Structure

```
ios/
├── project.yml                  # XcodeGen project definition
└── TimesheetApp/
    ├── Resources/               # Info.plist generated by XcodeGen
    └── Sources/
        ├── TimesheetAppApp.swift   # App entry point
        ├── AppState.swift          # Session state (email, server URL)
        ├── Models/                 # Codable API models
        ├── Networking/             # APIClient (async/await URLSession)
        └── Views/                  # SwiftUI screens
```
